# AX3600 刷机前准备清单（Wi-Fi 环境版）

> 你的场景：电脑只能连 Wi-Fi，路由器后台进得去但**没有外网**。
> 先说结论：**刷机能做，但缺少网线是本流程唯一的硬风险点**，见第 2 节。

---

## 1. 最关键的认知：我无法远程连你的路由器

我在你电脑上运行，**不在你家里那个局域网里**，所以 `ssh root@192.168.31.1` 我这边是连不上的。
实际分工是：

- **我负责**：生成命令/脚本、核对固件 hash、解析你贴回来的输出、判断每步是否正确、出错时定位原因；
- **你负责**：在 PowerShell 里粘贴我给的命令（或双击我生成的 `.ps1` 脚本）。

所以下面要准备的工具，是"让你能一条条执行、并把结果贴给我"的最小集合。

## 2. ⚠️ 硬风险：initramfs 阶段几乎没有 Wi-Fi

这是本次流程里最需要提前解决的一点：

| 阶段 | Wi-Fi 能不能用 | 说明 |
|---|---|---|
| 原厂固件（现在） | ✅ 能 | 你已经在用，SSH 也通了 |
| **boot 进 initramfs 后** | ❌ **基本不能** | OpenWrt 的 initramfs 是内存临时系统，**默认不带无线配置**（无 SSID、无密码），只起有线网口（默认 192.168.1.1） |
| 正式固件首启后 | ✅ 能 | 我们已预置 `99-wifi-firstboot`，自动开 `AX3600-Setup`，管理地址 192.168.2.1 |

也就是说：**从"重启进 initramfs"到"正式固件起来"这段时间，电脑和路由器必须靠网线相连**，否则你会既连不上 Wi-Fi、也无法下发刷写命令，只能干等或强制断电（危险）。

### 解决方案（三选一，按推荐度排序）

1. **买一个 USB 转 RJ45 网卡**（¥30–60，绿联/山泽等，免驱 RTL8153 芯片）——最省事，插上就能用，刷完可留着；
2. **借一台有网口的笔记本**，把固件和命令拷过去，刷完再换回来；
3. **确认你的台式机/笔记本其实有网口**（很多"没网线"只是没接，不是没口）。

> 如果三种都做不到，就必须改造流程（在原厂固件里就把正式固件直接 `mtd write` 到位、不经过 initramfs），
> 风险显著更高（写错分区直接砖），**不建议**，需要时再单独设计。

## 5. 只有 Wi-Fi 时的网络注意事项

1. **AP 隔离必须关闭**：如果这个 Wi-Fi 是访客网络或开了"客户端隔离"，电脑和路由器之间会被阻断（表现为 SSH 连不上但后台网页能开）。确认路由器后台没有开"访客网络/AP 隔离"。
2. **不需要外网**：`ssh`/`scp` 走二层内网，不需要 DNS、不需要出口，断网完全不影响。
3. **Windows 网络位置设为"专用"**：设置 → 网络和 Internet → Wi-Fi → 该网络 → 网络配置文件改为"专用"，避免防火墙策略变化影响。
4. **降级后 IP 是 192.168.31.1，刷完后是 192.168.2.1**：换 IP 后电脑可能缓存旧地址，必要时 `ipconfig /release` + `ipconfig /renew` 或重连 Wi-Fi。
5. **刷机后 SSID 变了**：正式固件起来后 Wi-Fi 名为 `AX3600-Setup`，密码 `AX3600-Setup-9pQ7xM2k`（首启脚本预置，登录后请立刻改）。

## 6. 刷前必做：分区备份（5 分钟，强烈建议）

在**现在的原厂 SSH 里**执行，把关键分区备份到电脑。ART（无线校准）和 bdata（SN/MAC）丢了几乎无法恢复，是变砖后最难救的部分。

```sh
# 在路由器上执行
cat /proc/mtd
mkdir -p /tmp/bak
nanddump -f /tmp/bak/mtd8_ART.img /dev/mtd8
nanddump -f /tmp/bak/mtd9_bdata.img /dev/mtd9
ls -l /tmp/bak
```

然后在电脑上（PowerShell，注意加老算法参数）：

```powershell
scp -O -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa root@192.168.31.1:/tmp/bak/*.img .
```

（`-O` 是让新版 scp 走旧 SCP 协议，老 dropbear 不支持 SFTP 时需要；若报错就改用 WinSCP 拖拽。）

备份完把 `sha256sum /tmp/bak/*.img` 的输出贴给我，我帮你核对文件完整性。
