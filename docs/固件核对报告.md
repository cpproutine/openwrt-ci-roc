## 四、刷入方式（stock 布局，保留原厂可回退）

stock 布局**不需要** initramfs 中转（该变体 `ARTIFACTS :=` 为空，本来也不产出 initramfs-factory.ubi）。原厂 1.0.17 固件自带 `ubiformat`，可直接刷到非当前启动分区。

```sh
# 1. 确认当前启动分区：0 = rootfs，1 = rootfs_1
nvram get flag_boot_rootfs

# 2. 确认分区索引
cat /proc/mtd

# 3a. 若返回 0 → 刷到 mtd13
ubiformat /dev/mtd13 -y -f /tmp/libwrt-...-factory.ubi -s 2048 -O 2048 \
  && nvram set flag_boot_rootfs=1 && nvram set flag_last_success=1 && nvram commit

# 3b. 若返回 1 → 刷到 mtd12
ubiformat /dev/mtd12 -y -f /tmp/libwrt-...-factory.ubi -s 2048 -O 2048 \
  && nvram set flag_boot_rootfs=0 && nvram set flag_last_success=0 && nvram commit

reboot
```

- 原厂系统留在另一分区，刷坏可改回 `flag_boot_rootfs` 回退。
- 后续升级用 `sysupgrade.bin`；注意 stock 变体的 `platform.sh` 是**写当前运行分区**（`CI_UBIPART` 取当前 flag），不重建分区。
- overlay 可用空间约 3.3 MiB（分区 35.75 − 镜像 32.38），因此后续不要指望往 overlay 装大包。
